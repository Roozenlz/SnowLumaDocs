SnowLuma stores configuration in two JSON files:

- **`config/onebot.json` + `config/onebot_<uin>.json`** — OneBot network adapters (HTTP/WebSocket listeners, reverse WS, HTTP event reporting).
- **`config/runtime.json`** — process-level settings (WebUI port, auto-injection toggle).

Both files are auto-generated on first run and normalized on every load.

## OneBot config

### File locations

```text
config/onebot.json          # global defaults
config/onebot_<uin>.json    # per-account overrides
```

- **Global**: `config/onebot.json` — the default for every account.
- **Per-account**: `config/onebot_<uin>.json` — overrides the global file.
- **Auto-generated**: missing per-account config or access tokens are written automatically in normalized form on first run.

### Default config

Adapters are grouped by kind under a single `networks` object:

```json
{
  "networks": {
    "httpServers": [
      {
        "name": "http-default",
        "enabled": true,
        "host": "0.0.0.0",
        "port": 3000,
        "path": "/",
        "accessToken": "auto-generated",
        "messageFormat": "array",
        "reportSelfMessage": false
      }
    ],
    "httpClients": [],
    "wsServers": [
      {
        "name": "ws-default",
        "enabled": true,
        "host": "0.0.0.0",
        "port": 3001,
        "path": "/",
        "role": "Universal",
        "accessToken": "auto-generated",
        "messageFormat": "array",
        "reportSelfMessage": false
      }
    ],
    "wsClients": []
  },
  "musicSignUrl": ""
}
```

<Callout type="info">
**Migrating from the old format**: earlier versions kept `httpServers` / `wsServers` arrays at the top level and used `httpPostEndpoints` for reporting. SnowLuma detects this layout, moves the entries into the `networks` object, renames `httpPostEndpoints` to `httpClients`, and writes the result back to disk. If you maintain configs by hand, use the new shape.
</Callout>

### Shared fields

Every adapter accepts these (`NetworkBase`):

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `name` | string | required | Identifier unique within its kind array; hot-reload addresses it by `(kind, name)`. |
| `enabled` | bool | `true` | Set `false` to keep the configuration but skip starting this adapter. |
| `accessToken` | string | auto | OneBot bearer / `?access_token=`. |
| `messageFormat` | string | `array` | `array` or `string` — controls whether the event `message` field is a segment array or a flattened string. |
| `reportSelfMessage` | bool | `false` | When `true`, this adapter sees `post_type='message_sent'` events. |

### `httpServers`

OneBot HTTP API listener.

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `host` | string | `0.0.0.0` | Bind address. |
| `port` | number | `3000` | Listen port. |
| `path` | string | `/` | API path prefix. |

### `httpClients`

Push events to external endpoints (formerly `httpPostEndpoints`).

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `url` | string | required | Report URL. |
| `timeoutMs` | number | `5000` | Request timeout. |

### `wsServers`

OneBot WebSocket server.

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `host` | string | `0.0.0.0` | Bind address. |
| `port` | number | `3001` | Listen port. |
| `path` | string | `/` | WebSocket path. |
| `role` | string | `Universal` | `Api`, `Event`, or `Universal` (**TitleCase**; older lowercase values are no longer accepted). |

### `wsClients`

Connect outbound to reverse WebSocket servers.

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `url` | string | required | Reverse WebSocket URL. |
| `role` | string | `Universal` | Same values as `wsServers.role`. |
| `reconnectIntervalMs` | number | `5000` | Reconnect interval; clamped to a `1000` minimum. |

### `musicSignUrl`

Optional URL for a custom music-card signing service. Empty string disables.

## Runtime config (`runtime.json`)

`config/runtime.json` carries process-wide settings — **not per-account**. A missing file, or one with missing fields, is backfilled and rewritten on load.

```json
{
  "webuiPort": 5099,
  "webuiHost": "127.0.0.1",
  "hookAutoLoad": false,
  "webuiTls": { "enabled": false },
  "trustProxy": "",
  "logMaxTotalMb": 1024,
  "logRetainDays": 7,
  "logPerUin": false
}
```

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `webuiPort` | number | `5099` | WebUI listen port; anything outside `1..65535` falls back to the default. |
| `webuiHost` | string | `127.0.0.1` | WebUI bind address. **Loopback only by default** — set `0.0.0.0` to reach it from another machine. Listener-level: change needs a restart. |
| `hookAutoLoad` | bool | `false` | Auto-inject the hook into every newly discovered QQ process. The Docker image turns this on via `supervisord.conf`. |
| `webuiTls.enabled` | bool | `false` | Serve HTTPS using `config/cert.pem` + `config/key.pem`. Listener-level: change needs a restart. |
| `trustProxy` | string | `""` | Trusted reverse-proxy directive used to resolve the client IP; empty means trust nobody. |
| `logMaxTotalMb` | number | `1024` | Aggregate size cap for every managed file under the log root. |
| `logRetainDays` | number | `7` | Calendar-day retention; `0` disables date-based deletion. |
| `logPerUin` | bool | `false` | Duplicate UIN-scoped lines into `logs/<uin>/` in addition to the shared log. |

<Callout type="warn">
**`webuiHost` defaults to `127.0.0.1`** — loopback only. In Docker, override it with `SNOWLUMA_WEBUI_HOST=0.0.0.0`, otherwise the published ports cannot reach the WebUI.
</Callout>

## Environment variables

Environment variables **win over** `runtime.json` and apply in memory only — they are never written back, which makes them the right knob for Docker and launchers.

| Var | Field | Notes |
| --- | --- | --- |
| `SNOWLUMA_WEBUI_PORT` | `webuiPort` | WebUI listen port. |
| `SNOWLUMA_WEBUI_HOST` | `webuiHost` | WebUI bind address; use `0.0.0.0` in Docker. |
| `SNOWLUMA_WEBUI_TLS` | `webuiTls.enabled` | `1` / `true` serves HTTPS, `0` / `false` off. |
| `SNOWLUMA_WEBUI_TRUST_PROXY` | `trustProxy` | Trusted proxy directive; `0` / `off` means trust nobody. |
| `SNOWLUMA_LOG_MAX_TOTAL_MB` | `logMaxTotalMb` | Log size cap. |
| `SNOWLUMA_LOG_RETAIN_DAYS` | `logRetainDays` | Log retention in days. |
| `SNOWLUMA_LOG_PER_UIN` | `logPerUin` | Per-UIN log directories. |
| `SNOWLUMA_HOOK_AUTOLOAD` | `hookAutoLoad` | `1` / `true` forces auto-injection on; `0` / `false` off. |
| `SNOWLUMA_LOG_LEVEL` | — | Log level (`error` / `warn` / `info` / `debug`). |
| `SNOWLUMA_VERBOSE_WARMUP` | — | Set to `1` for verbose friend / group / member warm-up logs. |
| `SNOWLUMA_DEV_MODE` | — | Set to `1` for dev mode (relaxes WebUI auth; local debugging only). |
| `SNOWLUMA_DEV_WEBUI` | — | Set to `1` to force-start the bundled WebUI under dev mode. |
| `SNOWLUMA_ACCEPT_EULA` / `SNOWLUMA_ACCEPT_PRIVACY` | — | Set both to `1` to skip the first-boot consent page for unattended deployments. |

## Port conflicts

If `3000` / `3001` / `5099` are taken, change the matching `port` / `webuiPort` and restart. Docker users can also remap host ports via Compose (see [Docker deployment](/docs/docker)).
